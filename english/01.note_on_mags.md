# 英文雜誌筆記 Cheat Sheet


| 雜誌 Section | Context｜何時記 | Method｜怎麼記 | Example｜範例 |
|---|---|---|---|
| **Title 標題區** | 開始閱讀前 | 圈出關鍵字，預測文章主題 | `office tool → esport`<br>預測：Excel 如何變成競賽項目 |
| **Article 文章區** | 遇到重要或不熟的字詞 | 圈出關鍵字，簡記中文；片語整組標示 | `race against time`＝與時間賽跑 |
| **Article 文章區** | 遇到難懂的長句 | 找主詞、動詞與句子主幹；補充內容加括號 | `Players / must pass / several rounds.` |
| **Article 文章區** | 遇到代名詞 | 畫箭頭指出代名詞所指的對象 | `It → Excel`<br>`them → most people` |
| **Article 文章區** | 看到連接詞 | 圈起來並註明邏輯功能 | `Instead`＝對比<br>`First / Then`＝順序 |
| **Paragraph 段落旁** | 讀完一個段落 | 找主題句，在旁邊寫一句段落大意 | 選手必須通過多個回合，才能進入現場賽 |
| **Words / Vocabulary 單字區** | 複習課文重點字詞 | 記錄詞性、意思及常見搭配 | `organize (v.)` 整理<br>`organize A by B` |
| **Advanced Words 補充單字區** | 補充文章主題相關單字 | 將單字依主題分類，不必全部抄寫 | 比賽：`competition`、`round`、`match` |
| **Enjoy Plus 背景補充區** | 閱讀背景、文化或專有名詞 | 只整理與文章理解有關的資訊 | `esport`＝`electronic sport` |
| **Questions 題目區** | 完成選擇、克漏字或閱讀題 | 寫「答案＋文章證據」，必要時排除錯誤選項 | `D must pass`<br>證據：進入小組賽前的必要條件 |
| **Summary 摘要區** | 完成文章與題目後 | 用一至兩句寫出主題、變化與重點 | Excel 從辦公工具發展成國際競賽項目 |

## 最小完成標準

| Section | 至少完成 |
|---|---|
| **Title** | 1 個主題預測 |
| **Article** | 5 個重要字詞、1 個長句拆解 |
| **Paragraph** | 每段 1 句大意 |
| **Vocabulary** | 3 個單字或片語用法 |
| **Questions** | 每題標出答案與證據 |
| **Summary** | 1 至 2 句全文摘要 |

> **標題做預測、文章做理解、單字學用法、補充建背景、題目找證據、摘要做統整。**
